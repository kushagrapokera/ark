# Changelog

All notable changes to ark are documented here.

## 0.1.0-beta — 2026-11-27

- Initial public Linux x86_64 beta.
- Read-only code viewer with syntax highlighting, search, and selection.
- Real terminal tabs with drag selection and clipboard copy.
- Clean terminal background rendering and blinking carets.
- Agent launcher tabs for tools such as OpenCode.
- Live filesystem refresh.
- Git status badges and per-file diff marks.
- Commit and push panel.
- Whitelisted `.env`, YAML, and TOML config editors.
- Bundled fonts and bounded caches.
