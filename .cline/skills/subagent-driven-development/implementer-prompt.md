# Implementer brief

Derived from obra/superpowers; see LICENSE.upstream.

Provide task requirements, relevant interfaces, working directory, exact permitted
files, baseline/current state, and expected verification commands. Implement only
this task using TDD for behavior changes. Preserve existing work and tests. Do not
delegate or commit. Escalate consequential unknowns rather than guessing.

Use the failure-loop record; after three failed fixes, diagnose before more edits.
Return changed files, exact commands/results, requirement coverage, and remaining
concerns. Self-review does not replace the controller's independent reviewer.
