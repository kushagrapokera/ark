# Task reviewer brief

Derived from obra/superpowers; see LICENSE.upstream.

Provide original task requirements, binding project constraints, relevant artifacts,
and exact change identity. Review the real implementation and tests; treat author
claims as unverified. Check both requirement compliance and task code quality.
Remain read-only on the shared checkout; do not delegate. Run focused checks where
feasible, isolating artifacts. Return PASS/FAIL/NEEDS_REVIEW, evidence with file/line,
commands/results, and unverified requirements. Do not invent requirements or dismiss
a contract violation because the plan included it.
